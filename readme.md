# MegaD HomeAssistant integration

[![hacs_badge](https://img.shields.io/badge/HACS-Custom-orange.svg)](https://github.com/hacs/integration)

Интеграция с [MegaD-2561, MegaD-328](https://www.ab-log.ru/smart-house/ethernet/megad-2561)

[Сообщить о проблеме](https://github.com/minakov/mega_hacs/issues/new?assignees=&labels=&template=bug-report.md&title=) | [Предложение об улучшении](https://github.com/minakov/mega_hacs/issues/new?assignees=&labels=enhancement&template=enhance.md&title=)

## Основные особенности

- Настройка в веб-интерфейсе + yaml
- Все порты автоматически добавляются как устройства (для обычных релейных выходов создается
  `light`, для шим — `light` с поддержкой яркости, для цифровых входов `binary_sensor`, для датчиков `sensor`)
- Поддержка rgb+w лент как с использованием диммеров, так и адресных лент на чипах ws28xx и подобных
- Плавное диммирование для любых диммируемых объектов (в том числе с аппаратной поддержкой и без)
- Возможность работы с несколькими megad
- Обратная связь по http
- Автоматическое восстановление состояний выходов после перезагрузки контроллера
- Автоматическое добавление/изменение объектов после перезагрузки контроллера
- События на двойные/долгие нажатия
- Последовательное выполнение команд без конкурентного доступа к ресурсам megad — каждая следующая команда отправляется только после получения ответа о выполнении предыдущей
- Поддержка [ds2413](https://www.ab-log.ru/smart-house/ethernet/megad-2w), в том числе нескольких шин (начиная с версии 0.4.1)
- Поддержка расширителей MegaD-16I-XT, MegaD-16R-XT, MegaD-16PWM (начиная с версии 0.5.1)
- Поддержка всех возможных датчиков в режиме I2C-ANY (начиная с версии 0.6.1)

## Установка

Если вы уже устанавливали HACS, просто поищите в списке интеграций MegaD. Если нет — сначала установите HACS: [инструкция](https://hacs.xyz/docs/installation/installation)

Далее внутри интерфейса HACS: `HACS → Integrations → Explore`, в поиске ищем MegaD.

После установки потребуется прописать настройки каждого контроллера в интерфейсе HA.

**Альтернативный способ установки** — через терминал из папки с конфигом:

```shell
wget -q -O - https://raw.githubusercontent.com/minakov/mega_hacs/master/install.sh | bash -
```

Не забываем перезагрузить HA.

## Обновления

Обновления выполняются в меню HACS. Чтобы вручную проверить наличие обновлений — нажмите три точки возле интеграции и выберите `Обновить информацию`.

## Зависимости

Для максимальной скорости реакции рекомендуется выключить `имитацию http-ответа` в настройках интеграции и настроить proxy_pass к HA с помощью [специального аддона](https://github.com/minakov/mega_addon/tree/master/mega-proxy).

Обновление прошивки MegaD можно делать из HA с помощью [аддона](https://github.com/minakov/mega_addon.git).
